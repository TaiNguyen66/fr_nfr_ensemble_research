# ICIIT 2027 submission version

ACM `sigconf` version of the paper for the 12th International Conference on Intelligent Information Technology (ICIIT 2027, Ho Chi Minh City, 4–7 March 2027). The course version (IEEE format) is in `../paper/`.

- Overleaf: zip the contents of this folder (`main.tex` at the root), *New Project → Upload Project*, compiler pdfLaTeX. Overleaf provides `acmart.cls` and `ACM-Reference-Format.bst`.
- Content (sections, tables, figures, bibliography) is copied from `../paper/`. Change content there first, then copy the changed files here.
- Differences from `../paper/`: ACM class and top matter (CCS concepts, keywords), the supervisor listed as third author instead of an acknowledgment, `\Description` for both figures, and `url` fields dropped from bibliography entries that have a DOI (the ACM style prints the DOI link itself).
