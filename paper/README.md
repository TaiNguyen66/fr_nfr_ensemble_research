# Paper source

LaTeX source of *How Much Does Evaluation Leakage Inflate FR/NFR Requirements Classification? A Leakage-Aware Re-Evaluation of Single and Ensemble Classifiers* (IEEEtran conference format, 8 pages).

| Path | Content |
|---|---|
| `main.tex` | Main file (IEEEtran, pdfLaTeX + BibTeX) |
| `sections/*.tex` | Abstract, Introduction, Related work, Study design, Results, Discussion, Threats to validity, Conclusion |
| `tables/*.tex` | Tables I–VII, **generated** by `python -m src.paper_tables`; do not edit by hand |
| `figures/summary_deltas.pdf` | Fig. 2, generated by `python -m src.paper_tables` |
| `figures/design.tex` | Fig. 1, evaluation design (TikZ) |
| `references.bib` | 43 entries, each with a DOI URL or the publisher's page |

## Build

**Overleaf:** zip the contents of this folder so that `main.tex` is at the root of the zip, then *New Project → Upload Project*. Set the compiler to pdfLaTeX and recompile twice.

**Local:**

```powershell
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

## Regenerating tables and figures

From the repository root, after `python -m src.analyze_results`:

```powershell
python -m src.paper_tables
```

All numbers in the paper come from `results/tables/*.csv` through this script.
